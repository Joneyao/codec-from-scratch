# Project-level Skills

本目录存放 codec-from-scratch 项目开发过程中沉淀的可复用 skills，随仓库版本管理，供后续模块开发和贡献者复用。

## 计划中的 skills

| Skill | 用途 |
|---|---|
| `bitstream-debugging` | 位流对齐、字节 dump、与参考实现 diff 的标准流程 |
| `codec-chart-export` | 从 C++ 模块导出真实调试数据 + matplotlib 绘制配图的规范 |
| `spec-clause-lookup` | 在 docs/spec-reference 里定位 ITU-T 条款号的检索技巧 |

每个 skill 一个子目录，含 SKILL.md。开发中遇到的踩坑经验沉淀为 skill 里的 learnings。
