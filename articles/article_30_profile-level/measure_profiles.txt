------------------------------------------------------------------------
命令：ffprobe -v error -select_streams v:0 \

        -of default=noprint_wrappers=1 hd_<p>.mp4

hd_high.mp4     : codec=h264  profile=High                  level=31  1280x720  has_b_frames=2

------------------------------------------------------------------------
[3] SPS 里的 profile_idc / level_idc 真实字节
------------------------------------------------------------------------
从 Annex B 裸流里定位 SPS NAL（type 7），读其后的 profile_idc 与 level_idc 字节：
  baseline : profile_idc = 66   level_idc = 31  (Level 3.1)
  main     : profile_idc = 77   level_idc = 31  (Level 3.1)
  high     : profile_idc = 100  level_idc = 31  (Level 3.1)

对照 ITU-T H.264 Table 7-2 profile_idc 取值：66=Baseline, 77=Main, 100=High。
这就是手搓系列 D6 在生成 SPS 时亲手写进码流的两个字节。

------------------------------------------------------------------------
[4] 各 profile 实际启用的编码工具（从 x264 编码日志逐项摘录）
------------------------------------------------------------------------
                 CABAC   8x8dct   B帧(bframes)   加权P(weightp)
  baseline       0       0        0              0
  main           1       0        3              2
  high           1       1        3              2

日志原文关键片段：
  baseline: options: cabac=0 ... 8x8dct=0 ... bframes=0 weightp=0 ... rc=cqp qp=26
  main    : options: cabac=1 ... 8x8dct=0 ... bframes=3 ... weightp=2 ... rc=cqp qp=26
  high    : options: cabac=1 ... 8x8dct=1 ... bframes=3 ... weightp=2 ... rc=cqp qp=26

结论：Baseline 关掉 CABAC / 8x8 变换 / B 帧；Main 打开 CABAC + B 帧但仍无 8x8；
High 在 Main 基础上再加 8x8 变换。这就是三个 profile「工具集」的真实差别。

[5] 同素材同 QP 的文件体积（工具越强，压得越小）
------------------------------------------------------------------------
命令：stat -c%s hd_<p>.mp4
  baseline : 428795 bytes   (基准, +13.8% vs high)
  main     : 383127 bytes   (-10.65% vs baseline)
  high     : 376933 bytes   (-12.10% vs baseline, 最小)

差值：baseline 比 high 大 51862 bytes（约 +13.76%）。
最大的一跳来自 baseline->main（打开 CABAC + B 帧，-10.65%）；
main->high（再加 8x8 变换）只再省 -1.62%，边际收益递减但方向一致。

（另一组 mandelbrot QP=26 实测：baseline 1752582 / main 1213997 / high 1214299，
