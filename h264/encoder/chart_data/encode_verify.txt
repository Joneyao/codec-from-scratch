## 诚实说明（不夸大，本系列的价值在于诚实）
# 1) 范围：只做 I_4x4 帧内 I 帧；不做 P 帧（帧间）、不做 Intra_16x16、色度不
#    编码残差(cbp_chroma=0，色度仅帧内预测)。这些是主动收窄，均如实标注。
# 2) "残差丢弃"是关键的自洽性代价：本仓库 decoder 的 CAVLC 码表有两处历史笔误
#    （coeff_token 的 4<=nC<8 档、total_zeros 的 total_coeff==4 行），且这些非
#    标准码字 ffmpeg 不认。为让"自解 + ffmpeg"双双通过，编码器主动回避会命中
#    这两条路径的块，把它们的残差丢弃（编成空块，只保留帧内预测）。故 PSNR 未
#    到"逐像素完美对齐"，而是 33~37 dB 的量级——这是在"不改 decoder 代码"约束
#    下能达到的、真实且双端自洽的结果。
# 3) PSNR 口径：自解码器输出的是编码尺寸(304x208)、经去块滤波；ffmpeg 输出是
#    裁剪后真实尺寸(300x200)。两者与原图对比的 PSNR 落在同一量级（差 < 0.5 dB），
#    差异来自去块滤波与色彩空间约定(编码器用 BT.601 全范围，ffmpeg 用其默认矩阵)。
# 4) "nonzero_luma_coeffs 编码=1152、自解=1152 完全一致"是比 PSNR 更硬的比特级
#    证据：熵解码逐系数还原了编码器写入的每一个量化系数。
